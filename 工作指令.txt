归档状态把导出按钮也一起藏了，这是条件判断过宽。归档应该只禁用**编辑/生成类**操作，**导出/查看类**功能要保持可用。

---

## Kimi Code 执行提示词

**任务：修复已归档项目隐藏导出按钮的问题**

---

### Phase 1: 定位归档状态的按钮隐藏逻辑

1. 打开框架搭建步骤的组件文件（渲染"已完成 · 已归档"状态的地方）。
2. 找到判断按钮显示/隐藏的条件代码，通常类似：
   ```tsx
   {status !== 'archived' && (
     <>
       <Button>重新导入</Button>
       <Button>重新生成</Button>
       <Button>导出文档</Button>  {/* 被一并隐藏 */}
       <Button>下一步</Button>
     </>
   )}
   ```
3. 或可能是：
   ```tsx
   const isArchived = project.status === 'archived';
   // 后面统一用 isArchived 控制所有按钮
   ```

---

### Phase 2: 拆分按钮的显示条件

**归档状态下应保留的按钮**：
- ✅ **导出文档** — 归档项目仍可导出 Word
- ✅ **查看/展开** — 卡片展开收起不受影响

**归档状态下应隐藏的按钮**：
- ❌ 重新导入
- ❌ 重新生成
- ❌ 下一步（或改为"已归档"禁用状态）

**修改逻辑**：

```tsx
const isArchived = project.status === 'archived';

// 编辑类按钮
{!isArchived && (
  <>
    <Button>重新导入</Button>
    <Button>重新生成</Button>
    <Button>下一步</Button>
  </>
)}

// 导出按钮 — 始终显示
<<Button>导出文档</Button>
```

或如果按钮组是统一渲染的数组/配置，在配置中增加 `hideOnArchived: boolean` 字段，导出按钮设为 `false`。

---

### Phase 3: 验证

1. 将一个项目标记为已归档（或进入已归档的"敦煌飞天"项目）。
2. 确认框架搭建右上角**仍显示"导出文档"按钮**。
3. 点击导出，确认 Word 文件正常下载且内容完整。
4. 确认"重新导入"、"重新生成"、"下一步"按钮确实已隐藏。

---

**执行**：Phase 1（定位条件）→ Phase 2（拆分归档判断）→ Phase 3（验证）。
