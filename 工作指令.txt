## Kimi Code 执行提示词

**任务：角色设定卡片布局重构 —— 图片移至右侧**

---

### Phase 1: 检查角色设定数据结构

1. 确认角色设定数据是否包含 `imageUrl` 或 `imageId` 字段，用于关联该角色的生图。
2. 如果当前角色数据中没有图片字段，检查资产库（`Asset` 表）中角色图片的存储方式：
   - 是否通过 `projectId` + `stepName = 'character_design'` + `characterId` 关联？
   - 还是通过 `character.imageUrl` 直接存储？
3. 确认前端当前是如何渲染角色图片的（可能是在角色卡片顶部、或独立区域、或只在资产库展示）。

---

### Phase 2: 角色卡片布局重构

**当前布局**：文字内容纵向排列，图片可能在卡片顶部或独立区域。

**目标布局**：左右分栏
```
┌─────────────────────────────────────────┐
│  char_001  陈远  主角                    │
├──────────────────────┬──────────────────┤
│  基础设定            │                  │
│  文物修复专业大学生...│   [角色生图]     │
│                      │                  │
│  形象外貌            │   已选定的角色基准 │
│  身形清瘦但肩背挺拔...│                  │
│                      │                  │
│  性格深度            │                  │
│  理性与感性的矛盾体...│                  │
│                      │                  │
│  ...                 │                  │
└──────────────────────┴──────────────────┘
```

**具体修改**：
1. 将角色卡片内部改为**左右两栏布局**：
   - 左侧：文字信息区（基础设定、形象外貌、性格深度、口头禅、人际态度、记忆点）
   - 右侧：图片展示区
2. **右侧图片区**：
   - 显示该角色的生图（从资产库或角色数据中获取）
   - 图片下方标注："已选定的角色形象"（类似视觉风格卡片的"已选定的风格基准"）
   - 图片圆角、阴影与视觉风格卡片的风格基准图一致
3. **响应式**：在窄屏下（如移动端），左右布局自动切换为上下布局（图片在上，文字在下）。

---

### Phase 3: 图片数据源绑定

1. 如果角色数据中有 `imageUrl`：直接绑定。
2. 如果角色数据中没有图片字段，需要：
   - 在角色生成完成后，将生图 URL 写回角色数据（`framework.characters[i].imageUrl`）
   - 或在渲染时从资产库查询该角色的图片（通过 `characterId` 或 `characterName` 匹配）
3. 如果角色有**多张**生图（如不同角度），右侧显示**当前选定的主图**，并提供小图切换（可选，先做单张）。

---

### Phase 4: 样式统一

1. 右侧图片区域的样式与**视觉风格卡片**的风格基准图保持一致：
   - 图片圆角（如 `rounded-lg` 或 `rounded-xl`）
   - 图片阴影（如 `shadow-md`）
   - 图片下方标注文字样式（灰色小字）
   - 图片与文字区域之间的间距（如 `gap-6` 或 `gap-8`）
2. 文字区域保持现有排版，但适当缩小行距或字号，确保左右视觉平衡。
3. 如果图片高度超过文字区域，图片底部与文字底部对齐（或图片自适应高度）。

---

### Phase 5: 验证

1. 进入人物设计步骤，确认每个角色卡片显示为左右布局。
2. 右侧显示该角色的生图，标注"已选定的角色形象"。
3. 确认图片样式与视觉风格卡片的风格基准图一致。
4. 在移动端/窄屏下测试，确认布局切换为上下结构。
5. 如果角色尚未生图，右侧显示占位图或空状态提示。

---

**执行顺序**：Phase 1（数据结构）→ Phase 2（布局重构）→ Phase 3（数据绑定）→ Phase 4（样式统一）→ Phase 5（验证）。

**先执行 Phase 1，确认角色图片当前存储在哪里（角色数据内还是资产库），再调整布局。**
