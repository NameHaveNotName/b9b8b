   - .env.local

   - public/mock-storage/（大文件，已迁移到 Supabase）
   - 如缺失，补充进 .gitignore
3. 配置 git user（如未配置）：
   git config user.email "2627312372@qq.com"
   git config user.name "康泽铭"
4. 添加所有文件并提交：
   git add .
   git commit -m "init: project setup with Supabase + Vercel"
5. 创建并切换到 main 分支：
   git branch -M main

### Phase 2：GitHub 仓库创建与推送
检查系统是否安装了 GitHub CLI (gh)：
- 若已安装：执行 gh repo create b9b8b --public --source=. --remote=origin --push
- 若未安装：输出以下指导给用户，暂停执行等待用户反馈：

【需要用户手动操作】
1. 打开 https://github.com/new
2. Repository name 填：b9b8b
3. 选择 Public（或 Private，但 Private 需 Vercel Pro）
4. 不要勾选 "Add a README" 或 ".gitignore"
5. 点击 Create repository
6. 复制页面上的这两行命令（HTTPS 或 SSH 均可）：
   git remote add origin https://github.com/你的用户名/b9b8b.git
   git push -u origin main
7. 把命令粘贴到终端执行，或告诉我你的 GitHub 用户名，我帮你生成精确命令

- 若用户提供了 GitHub 用户名和仓库名：
   git remote add origin https://github.com/用户名/b9b8b.git
   git push -u origin main

### Phase 3：Vercel 连接 GitHub（用户手动 UI 操作）
推送成功后，输出以下精确步骤给用户：

1. 打开 Vercel Dashboard：https://vercel.com
2. 进入项目 b9b8b → 顶部 Tab 找 "Settings" → 左侧 "Git"

6. 确认连接后，Vercel 会自动重新部署一次
7. 以后每次执行 git push，Vercel 自动构建部署（约 1-2 分钟）
