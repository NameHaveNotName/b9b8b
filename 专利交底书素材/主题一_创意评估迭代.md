# 主题一：影视创意方向的多维度 AI 评估与反馈迭代优化方法

> 检索范围：`app/api/projects/[id]/steps/ideation/**`、`components/workflow/IdeationDeepenPanel.tsx`、`lib/workflow-state.ts`、`lib/workflow-executor.ts`、`prisma/schema.prisma`  
> 检索关键词：`ideation`、`retentionScore`、`qualityScore`、`concerns`、`improvementOptions`、`CreativeIteration`、`versionNumber`、`selectedImprovement`、`customFeedback`

---

## 技术问题

### 现有技术的不足

传统影视创意工具在 AI 辅助阶段通常只完成“一次性生成”，存在以下问题：

1. **缺乏对创意概念本身的量化评估**：多数工具仅输出文本方向，没有针对“与原始输入的契合度”和“作为影视创意的完成度”给出可对比的分数。
2. **改进方向依赖用户自行总结**：用户看到多版创意后，只能凭感觉选择，缺少 AI 主动提炼的短板与可操作建议。
3. **版本历史与反馈链路断裂**：历史版本散落，无法把“用户选了哪条改进建议”作为上下文注入下一轮生成，导致迭代方向不可控。
4. **阶段边界模糊**：创意扩散阶段容易越界输出幕结构、角色设定、分镜感等不属于本阶段的内容。

本系统通过 `CreativeIteration` 模型、`evaluate` 与 `deepen` 两个 API，以及前端 `IdeationDeepenPanel`，把“评估 → 选方向 → 深化 → 版本切换”形成闭环。

---

## 技术手段

### 1. 创意扩散后的多维度评分逻辑

**文件路径**：`app/api/projects/[id]/steps/ideation/evaluate/route.ts`  
**行号范围**：9–103

系统定义了双维度评估接口：

```typescript
interface EvaluationResult {
  retentionScore: number   // 原内容保留度 0-100
  qualityScore: number     // 优秀程度 0-100
  concerns: string          // 核心顾虑（1 个最大短板）
  improvementOptions: string[]  // 改进选项（最多 5 个）
}
```

评估 Prompt 明确限定阶段边界（行 31–40）：

```text
你当前处于"创意扩散"阶段，只评估"创意概念"本身。
绝对禁止评估以下内容：
- 幕结构、起承转合、分段是否合理
- 角色数量、角色关系网是否完整
- 场景清单、场景动作描写是否到位
- 分镜感、镜头运动、画面切换
- 剧本格式、对白质量
```

评分规则（行 62–71）：

```text
1. retentionScore（原内容保留度 0-100）：
   - 评估当前版本与原始创意的契合程度
   - 如果当前版本明显偏离了原始输入的核心概念，必须打低分

2. qualityScore（优秀程度 0-100）：
   - 评估当前版本作为影视创意的吸引力与完成度
   - 考虑：故事钩子强度、世界观记忆点、情绪反差、独特视觉锚点
   - 如果当前版本基于改进方向真正优化了对应短板，分数必须上涨（至少 +5）
```

标准化输出（行 94–100）：

```typescript
const retentionScore = Math.min(100, Math.max(0, Number(parsed.retentionScore ?? parsed.retention_score ?? 50)))
const qualityScore = Math.min(100, Math.max(0, Number(parsed.qualityScore ?? parsed.quality_score ?? 50)))
const concerns = String(parsed.concerns ?? parsed.concern ?? '暂无顾虑')
const improvementOptions = Array.isArray(parsed.improvementOptions ?? parsed.improvement_options)
  ? (parsed.improvementOptions ?? parsed.improvement_options).map((o: any) => String(o))
  : []
```

> **未实现说明**：提示词中未将“新颖性、情感张力、可行性、视觉表现力”拆分为四个独立维度。当前系统仅使用 `retentionScore` 与 `qualityScore` 两个综合分数，`novelty`、`emotional`、`feasibility`、`visual` 未作为独立评分字段出现。

  const targetOrder = getStepOrder(targetStep);

      where: { id: projectId },
      select: {
        stepIdeaDone: true,
        stepFrameworkDone: true,
        // ...
      },
    });
    if (project) {
      const state: ProjectState = { /* ... */ };
      const dagOk = STEP_CONFIG[stepId].unlockCondition(state);
      return linearOk || dagOk;
    }
  }
  return linearOk;
}

## 技术效果

1. **量化评估可对比**：每轮创意迭代都会产出 `retentionScore` 与 `qualityScore`，并强制要求基于改进方向“至少上涨 5 分”，使迭代效果可度量。
2. **改进建议可落地**：`concerns` 只指出 1 个最大短板，`improvementOptions` 最多 5 条，避免泛泛而谈。
3. **反馈闭环**：用户选择的改进方向通过 `selectedImprovements` 注入 `deepen` Prompt，生成新版本后自动重新评估，形成“生成 → 评估 → 选择 → 深化 → 再评估”的闭环。
4. **版本可追溯**：`CreativeIteration` 表记录每次迭代的版本号、评分、顾虑、改进选项、用户选择与自定义反馈，支持历史版本切换（`isCurrent` 标记）。
5. **阶段边界受控**：评估与深化 Prompt 均明确禁止输出幕结构、角色设定、场景清单、分镜感、剧本格式，确保“创意扩散”阶段只优化创意概念本身。
6. **工作流解锁**：IDEATION 完成后，`markProjectStepDone` 将 `Project.stepIdeaDone` 置为 `true`，FRAMEWORK 等后续步骤通过 `STEP_CONFIG` 的 `unlockCondition` 解锁。
