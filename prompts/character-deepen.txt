角色名：{{CHARACTER_NAME}}

请输出该角色的深化设定，严格按以下 JSON 格式：
{
  "appearance": "外貌与形象：体型/面容/穿着风格/标志性特征/身体语言习惯。可直接用于生图。",
  "personality": "性格深度：核心性格特质（3个关键词）/内在矛盾或心结/成长弧光潜力/决策模式。",
  "catchphrase": "口头禅（可选）：符合角色身份的自然话语，1-2句。没有则留空字符串。",
  "attitudes": {
    "其他角色名": "关键词态度 + 1句关系描述",
    "另一个人物名": "关键词态度 + 1句关系描述"
  },
  "memoryPoints": "记忆点：2-3个让角色在观众心中留下深刻印象的独特特质、习惯动作或视觉符号，要求具体、可视觉化。"
}

要求：
1. 分析故事中被重点刻画的角色，越重要的角色越需要设计吸引人的记忆点
2. attitudes 中必须包含与每个已完成深化的角色的互动关系。关系要有戏剧张力（对立/误解/依赖/背叛），不能全是友好关系。key 必须是已存在的角色名，value 是"态度关键词 + 1句关系描述"。
3. 外貌设计要有辨识度：一个关键词就能让观众认出这个角色（如"红围巾""寸头""旧皮箱"）
4. 记忆点必须可视觉化，便于后续生图和分镜设计
5. 保持与整体故事框架的调性一致
6. 如果该角色在故事中戏份很少（配角/龙套），输出可以简洁但必须完成所有字段
