【分镜规划核心铁律（对齐生产 SOP）】
1. 叙事职责（不可替代证据）：
   - 生成约 {{ESTIMATED_SHOTS}} 个镜头（可浮动 2 个）。每个镜头必须提供一条不可替代的故事证据或情绪证据（在 keyAction 中写明：“【叙事职责】证明/展现... + 【核心动作】...”）。删除任一镜头都应导致因果链缺失，严禁堆砌无信息的纯氛围废镜。
2. 抽象心理与身份外化：
   - 禁止在 description 中只写“意识到危险”“决定反击”“展现出权威”等抽象词；必须转化为可见的画面证据（视线转向何处、表情微变化、停顿吸气、手部抓取何物、周围人如何反应）。
3. 动作物理链与自然稳定态（关键！）：
   - 每个镜头的 description 必须按以下顺序写清：`【视角与景别】+【空间位置与起始状态】→【运动路径/接触点/受力或交互过程】→【结束稳定态（供下一镜接续的位置與姿态）】`。
   - 若涉及复杂动作（奔跑、撞击、翻越、争夺、跌落等），不得把超过 2 个高风险动作状态塞进同一个 5s 镜头；必须在“落地站稳、门关上、抓取完成、转身停定”等自然稳定态切分镜头。
4. 跨镜头连续性与观察方式切换：
   - 相邻镜头在同一空间交接时，保持人物动作相位、轴线方向、光线方向、服装与道具状态连续，但必须改变景别或机位角度（如全景建立 → 中近景动作 → 近景反应特写），禁止相邻两镜采用完全相同的景别与构图造成视觉跳切。
5. 三种密度平衡与模型档位：
   - duration 表示最终成片中的“创作时长”，不是供应商单次生成时长或计费时长。允许 0.5–10 秒并可保留 1 位小数：快速反应/插入镜头通常 0.5–2 秒，一般动作 2–5 秒，复杂动作或情绪停留 5–10 秒。系统会把同一 generationUnitId 的短镜头合并为一个生成单元，再按模型限制计算实际生成与计费时长。
   - 为每个镜头指定 tier（模型档位）：
     - `hero`：高光镜头、关键情绪、复杂动作、核心反转、重要角色特写。使用最高质量模型。
     - `standard`：一般叙事镜头、对话、中近景动作。使用高性价比模型。
     - `budget`：建立空间的大全景空镜、过渡镜头、重复氛围、次要背景。使用最便宜模型。
   - 全场 `hero` 镜头占比建议 10–30%，`budget` 占比建议 20–40%，其余为 `standard`。
   - 真实视频模型能力如下。设计 generationUnitId 时，必须让同一单元内所有 duration 之和落在目标模型支持范围内；系统提交前仍会按离散档位或步进做安全裁剪。不要为了凑模型最低时长而虚增某个内部镜头，应通过同一生成单元内合理的切镜节奏承载完整时长：

JSON 字段规范（严格输出纯 JSON 数组，不要 Markdown 代码块）：
- shotId: "shot_XXX"（如 shot_001）
- actNumber: {{ACT_NUMBER}}
- sceneName: 准确且一致的场景空间名称（同一地点跨镜头名称必须统一）
- description: 结构化画面描述，格式建议为：“[客观/主观POV · 景别/机位] 起始状态（人物位置/朝向/持有物/环境光线）→ 动作过程（路径/接触点/视线与神态变化）→ 结束稳定态（定格姿态与交接方向）。”
- cameraMove: 固定镜头/推镜头/拉镜头/摇镜头/移镜头/跟镜头/升镜头/降镜头/手持镜头/轨道横移（单镜头只选一种主导运动）
- duration: 最终创作时长，0.5–10 秒，可保留 1 位小数；不得为了供应商最低计费时长而虚增镜头时长
- tier: "hero" | "standard" | "budget"（模型档位，决定生成时调用哪个视频模型）
- characters: 出场角色 ID 数组（如 ["char_001"]，纯空镜或纯主观物体特写可为 []）
- keyAction: "【叙事职责】本镜提供的故事/情绪证据；【动作节点】起点→结果稳定态"
- generationUnitId: 生成单元编号，如 "act1_u01"。同一编号的连续镜头必须由一次视频生成完整输出，并共同承担一个不可拆分的叙事任务。镜头数没有固定上限：由叙事节奏、单元总时长和模型能力决定；快节奏 10～15 秒单元可以明显多于 5 镜。
- generationUnitIntent: 该生成单元唯一的叙事职责，用一句可验证的话描述；同一 generationUnitId 的值必须完全一致。
- actionChainId: 连续动作链编号，如 "act1_chain01"。不可从中间切断的发力、接触、受力与结果动作必须使用同一编号；动作完成并进入稳定态后才可更换编号。
- continuityGroupId: 连续空间与状态编号，如 "act1_space01"。只有地点、时段、人物/道具状态、轴线和光向可自然接续时才可沿用。
- continuityFromPrevious: boolean。只有上一镜画面确实适合作为当前镜的构图/空间连续性参考时为 true；换场、跳时、蒙太奇或主观想象必须为 false。
- startsNewGenerationUnit: boolean。每个 generationUnitId 的第一镜为 true，其余为 false。
- unitBoundaryReason: 第一镜必须简述为何在此新开生成单元；非第一镜为空字符串。主要角色群转到另一条独立叙事线、主要故事场景发生实质改变时通常拆分，但不得机械按角色或地点数量拆分。以下情况优先保留为一个完整单元：两组角色以相似构图高频匹配跳切；快速经过多个非主要地点的蒙太奇；打斗、奔跑、越野等需要连续运动的复杂动作。大量公式、回忆叠化或 AE 式特效段落应在前后稳定边界单独成单元。
