# 主动修改准备包

申请号：2026109280496

发明名称：一种基于AI工作流的影视前期制作方法及系统

## 提交文件

1. `01_权利要求书全文替换页_原PDF.pdf`：拟提交的九项权利要求全文替换页，共2页。
2. `02_权利要求书修改对照页.pdf`：原八项权利要求与修改后九项权利要求的对应关系、修改摘要及原始依据。
3. `03_主动修改意见陈述正文_提交用.txt`：用于复制到专利业务办理系统意见陈述栏的正文。
4. `03_主动修改意见陈述正文_提交用.pdf`：陈述正文的归档版；只有系统要求上传正文附件时才使用。

## 内部复核文件

- `01_权利要求书全文替换页.docx`：九项权利要求可编辑版本。
- `02_权利要求书修改对照页.docx`：修改对照页可编辑版本。
- `03_主动修改意见陈述正文_提交用.docx`：意见陈述正文可编辑版本。
- `03_主动修改意见陈述正文及原始依据表.pdf`及同名DOCX：含提交前核对项和逐项依据，仅供申请人或代理人复核，不作为默认上传文件。

## 提交条件

仅在以下任一时点提交主动修改：

- 与实质审查请求同时提交；
- 收到《发明专利申请进入实质审查阶段通知书》之日起三个月内。

正式提交前，应从局端案卷确认当前审查文本仍为原八项权利要求，并核对系统中的申请号、通知书日期、发文序号、附件名称和页数。点击最终提交按钮前应再次人工确认。
