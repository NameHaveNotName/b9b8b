# 第五阶段实施状态

更新时间：2026-10-30（Asia/Shanghai）

## 已完成

- 正式 Prisma 加法迁移：内容类型、结构化载荷、不可变个人版本、附件、项目快照血缘、软删除字段。
- 旧个人图片在迁移中回填为第 1 版及主附件；保留旧 ID 和旧媒体字段供兼容读取。
- 删除资产相关请求内的运行时 DDL，生产部署由 `prisma migrate deploy` 和数据库契约检查负责。
- 个人资产拖入项目时，复制二进制到项目存储路径，再以项目资产绑定；项目运行时不再新增个人资产直连绑定。
- 同一项目同一来源版本唯一约束与并发去重。
- 上传、候选生成、直接生成、项目结果保存均创建不可变第 1 版和内容哈希（可取得原始 Buffer 时）。
- 结构化资产 API 与字段白名单/长度限制，支持角色卡、环境设定、故事模板、风格指南、文本。
- 个人资产三天软删除、恢复和回收站查询。
- 项目参考素材三天软删除；仍有有效绑定时拒绝删除。
- 每日低峰清理接口：鉴权、分批、引用检查、幂等重试边界；不使用前端轮询。
- 资产管理页新增结构化设定表单、结构化卡片、回收站切换与恢复。
- 生成工作台侧栏拆分为“项目素材 / 我的资产库”；个人结构化资产不再伪装成图片。
- 项目素材查询只返回未删除的项目快照，并在授权后生成可用媒体 URL。
- 结构化资产可拖入创意扩散或框架搭建配置区；系统先预览字段、冲突、强度与合并策略，确认后才复制项目快照并应用。
- 结构化载荷只允许白名单字段和长度上限；进入模型提示词时放入“用户创作约束”隔离区，防止把素材文字当作系统指令。
- 创意扩散、框架搭建及框架重试均读取已确认约束，并在步骤输出中保留约束快照。
- 配置区展示当前步骤已应用的资产约束，并允许显式移除。
- 项目生成结果保存到个人库时，可新建资产或作为已有视觉资产的新版本；新版本保留父版本与完整生成来源快照。
- 个人资产详情支持查看不可变版本与附件、切换当前版本，并可上传辅助参考图或新主图；每次变更均生成新版本，不覆盖历史。
- 九步首次生成与重试的可见输入快照已扩展到结构化资产约束；失败任务也会尽力保留实际提交配置，便于复盘。
- 九步工作台仅开放实际被后端支持的参考图编辑；图片步骤、宣传片和直生视频的模型/画幅会沿同一冻结快照提交，直生视频画幅不再被后端默认值覆盖。
- 视觉资产独立生成已改为“配置 / 执行”两栏：先现场生成最终提示词并展示参考图顺序、模型、画幅和点数，允许修改后再提交；候选结果及真实阶段记录统一显示在执行栏。
- 生产部署增加旧 `AssetBinding.userAssetId` 兼容迁移：复制媒体到项目路径、创建项目快照、再切断个人资产运行时引用；数据库契约校验覆盖新增版本、附件、项目约束和软删除字段。
- 结构化资产版本可以切换；附件写库失败时会清理刚上传的孤立对象。
- 新增结构化资产约束自检，当前自检 57 项全部通过。

## 部署说明

- 本机没有生产数据库直连配置，`prisma migrate status` 只能连接本地占位地址，因此没有从开发机直接修改生产库。
- Vercel 生产构建会按顺序执行 `prisma migrate deploy`、旧绑定对象复制、数据库契约校验；任一步失败都会阻止上线，避免半迁移部署。
