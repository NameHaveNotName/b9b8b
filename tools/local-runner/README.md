# 本地顺序生成工具

这个工具在本机启动一个长时间运行的控制台，通过已登录账号的 Cookie 调用线上服务器接口，按顺序推进项目生成。点数扣除、模型调用、权限校验仍然全部走服务器，本地只负责自动点击下一步、轮询状态、下载结果。

## 启动

```powershell
npm run local-runner
```

启动后打开：

```text
http://localhost:4317
```

## 使用

1. 在 Edge 中保持网站已登录，打开目标项目工作流页面。
2. 在浏览器开发者工具的 Network 请求里复制登录态 Cookie，粘贴到本地控制台。
3. 填入项目页面地址，例如 `https://b9b8b.vercel.app/project/xxx/workflow`。
4. 如创意评估已有多个方向，填写要使用的方向序号，序号从 `0` 开始。
5. 选择生成长宽比，例如 `16:9`、`9:16`、`1:1`。
6. 点击“保存配置”，再点击“开始”。

## 执行规则

- 每个大步骤完成后都会暂停，必须手动点击“继续”。
- 自动跳过：概念图、宣传片、生成尾帧。
- 会执行：直生视频。直生视频按片段逐个生成，不依赖尾帧。
- 分镜阶段会先生成文本/提示词，暂停给用户检查；继续后逐镜头生成图片。
- 直生视频阶段会先生成片段提示词，暂停给用户检查；继续后逐段生成视频。
- 风格图、人物图、分镜图、直生视频片段和直生视频合成都使用本地控制台选择的长宽比。
- 生成结果会自动下载到配置的本地目录。

## 注意

Cookie 等敏感配置保存在 `.local-runner/state.json`，该目录已加入 `.gitignore`，不要提交或分享。

如果 Windows 当前用户启用了代理，例如 Edge 正在使用 `127.0.0.1:7890`，启动器会自动读取并让 Node 请求走同一个代理。
